# EL BEM BEAUTY 2.0 — Firebase-ready migration

**Источник:** ZIP `EL_BEM_BEAUTY_2_BUILD_FIX_2026_10_18 (2)(1).zip`. Сохранены фирменная CSS-концепция, страницы, фотографии и основные пользовательские сценарии. Все бывшие зависимости и SQL-миграции Supabase удалены.

**Статус: подготовлен код Firebase, но это НЕ подтверждённый production-релиз.** Тесты ниже запускались без доступа к настоящему Firebase. Для запуска общей базы нужны собственный Firebase-проект, конфигурация, публикация Firestore/Storage Rules и Cloud Functions, а также реальные ручные тесты. Не принимайте реальные данные клиентов до проверки правил доступа, антиспама, календаря и политики персональных данных.

## Быстрый запуск в VS Code (локальное DEMO)

1. Установить Node.js 22 и npm.
2. Открыть эту папку через VS Code.
3. Терминал в корне проекта: `npm install`.
4. Запуск: `npm run dev`.
5. В открытом браузере проверить страницы. **Без заполненного `.env` это локальное DEMO**: нет реальной межустройственной синхронизации, защищённого входа и серверных бронирований.
6. Для проверки кода: `npm run typecheck`, `npm run check:i18n`, `npm run build`.

## Что входит

- React 19, Vite 6, TypeScript; отдельные URL страниц через React Router и `vercel.json` для SPA.
- Существующий дизайн Editorial Beauty / кремово-бордовая гамма, адаптивная верстка, музыкальная кнопка, WhatsApp.
- Выбор языка KG / RU / EN, тема светлая/тёмная, разделы услуг, мастеров, обучения, магазина, галереи, отзывов, «О нас», контактов, аккаунта.
- Корзина, оформление заказа, избранное с локальным сохранением, категории, поиск, подробные карточки.
- Firebase Auth (клиентские аккаунты и отдельная серверная роль администратора); изменение пароля владельцем из админки.
- Firestore с правилами доступа; Firebase Storage для фото и музыки; Functions v2 для свободных временных слотов, недублируемых записей, расчёта цен на сервере, заказов и статусов.
- Админ-панель услуг, мастеров, товаров, категорий, записей, рабочих часов, заказов, галереи, отзывов, контента и настроек.
- Отзывы от зарегистрированных пользователей проходят модерацию.
- Демонстрационные данные для отдельного, необязательного начального импорта.

## Пример команд

```bash
npm install
npm run dev
npm run typecheck
npm run check:i18n
npm run build
node --test functions/tests/functions.test.cjs
```

Firebase Functions требуют отдельного `npm install` в каталоге `functions`, а для размещения требуется тариф **Blaze с подключенным платёжным аккаунтом**. Blaze имеет бесплатные квоты, но превышение квот, некоторые операции и ресурсы могут тарифицироваться. Настройте бюджетные предупреждения. Статические изменения фронтенда сами по себе не подключают базу.

## Важно перед передачей реальному салону

Контакты, адрес, ассортимент, фотографии, прайс и данные мастеров необходимо проверить у владельца. Сейчас часть контента служит **DEMO**. Не вставляйте ключи администратора, Firebase service-account JSON или пароли в `.env` / GitHub / Vercel. Поля `VITE_FIREBASE_*` — публичные настройки веб-приложения, а не серверные секреты.

**Отдельная оговорка:** существующий UI и ряд новых модулей ещё нуждаются в полноценном E2E-тестировании, проверке мобильного вида и реальном деплое; см. `QA_REPORT_RU.md`.
