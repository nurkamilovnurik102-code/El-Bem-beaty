# Проверка критериев «Окурмен»

Сверено с приложенным PDF `Финальный проект(8).pdf`. Важно различать **реализовано в коде** и **проверено на опубликованном сайте**. Здесь нет утверждений о проведённом деплое, которого не было.

| Обязательный критерий | Реализация | Подтверждение |
|---|---|---|
| Минимум 30–40 React-компонентов | ~35 именованных UI-компонентов в `App.tsx`, `media.tsx`, `components/Shared.tsx` | Статическая инвентаризация; структура нуждается в дальнейшем рефакторинге |
| API-данные | Firestore SDK + callable Cloud Functions | Код есть; живая сеть не проверена |
| Vercel deploy | `vercel.json` и Vite сборка | Публикация не выполнена |
| Корзина | Есть, изменение количества и локальное сохранение | Требуется браузерный тест |
| Бронирование | Календарь, мастер, услуги, защита пересечения на сервере | 3 изолированных серверных теста пройдены; реальная среда не проверена |
| Регистрация / вход | Firebase Auth Email/Password, выход, восстановление | Код есть; реальная среда не проверена |
| Заказ / купить | Реальная callable-процедура с серверной ценой | Изолированный тест пройден; реальная среда не проверена |
| Админ-панель | Защищённая роль, CRUD, расписание, записи, заказы, контент | Код есть; браузерная проверка нужна |
| Подробное описание | Отдельный экран деталей услуги, товара, мастера | Код есть |
| Поиск по имени | Услуги и товары | Код есть |
| Фильтрация | Категории услуг и товаров | Код есть |
| Добавить / удалить товар | Редактор товаров админ-панели | Код есть; Firestore надо проверить |
| Перевод KG / RU / EN | `react-i18next`, JSON, три прямых переключателя | JSON ключи сверены; полноту перевода необходимо проверить вручную |
| Адаптивность | Сохранён фирменный адаптивный CSS | Скриншоты 320–1920px не проверены в браузере |
| Оформить заказ | Корзина + данные клиента + server callable | Код есть |
| Бургер-меню | Есть в исходном дизайне | Код есть |
| День / ночь | Переключатель с сохранением | Код есть |
| Избранное | Сердечки и локальное сохранение | Код есть |
| Отзывы / рейтинг | 1–5 звёзд, форма, модерация | Изолированный тест сохранения отзыва пройден |

**Дополнительные пункты в PDF** (JWT/OAuth, пагинация, charts, оплата и др.) не следует считать все обязательными. В текущем архиве отсутствуют платёжная интеграция, Telegram-бот, статистические графики и OAuth. Telegram — ручной переход в чат.

Критерии защиты также включают 5-минутную презентацию, теоретические билеты, портфолио, GitHub и резюме. Данный ZIP сам по себе не обеспечивает выполнение этих частей экзамена.
